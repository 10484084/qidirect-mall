> 覆盖范围：`mall-api` 全部接口、`mall-admin` 全部接口、`mall-admin-web` 30 个页面、`mall-h5` 20 个页面及全部业务规则。
> 目标环境：`https://mall.76779.cn`（生产仅只读）／本地 `localhost:8080/8081/5173/5174`（写操作）
> 分支：`1.0`    编写日期：2026-11-21

## 0. 通用约定

### 0.1 环境

| 端 | 地址 |
|---|---|
| H5 | `https://mall.76779.cn/h5/` |
| 后台 | `https://mall.76779.cn/admin-web/` |
| 门店接口 | `https://mall.76779.cn/api` |
| 后台接口 | `https://mall.76779.cn/admin` |

### 0.2 账号

| 角色 | 账号 | 说明 |
|---|---|---|
| 超管 | admin / admin123 | 生产默认口令，上线前必须改（SEC-001） |
| 门店 | username=手机号 | 后台「设置登录密码」后可用 |
| 门店短信 | 手机号+验证码 | 生产真实短信；本地 mock |

### 0.3 优先级 / 判定

- P0 主流程与资金；P1 重要功能；P2 次要/体验。
- 结果：通过 / 失败 / 阻塞 / 不适用 / 未执行。
- **生产只读**；写操作一律在测试环境执行。

### 0.4 状态与枚举（断言依据）

| 对象 | 取值 |
|---|---|
| 门店状态 `status` | 1 正常，2 冻结 |
| 实名 `auth_status` | 0 未认证，1 待审/已提交，2 已认证 |
| 支付单 `status` | 0 待支付，1 支付中，2 已支付，3 支付失败，4 已关闭，5 已退款 |
| 支付渠道 `channel` | 1 JSAPI，2 聚合码，3 线下收款 |
| 订单 `status` | 0 待支付，1 待发货，2 已发货，3 已完成，4 已取消 |
| 提现 `status` | 0 待审核，1 待打款，2 已打款，3 已驳回，4 打款失败 |
| 提现方式 | 1 现金，2 转账，3 刷卡 |
