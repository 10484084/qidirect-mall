# Checklist

> 业务口径以 spec.md 的「口径裁定」为准。

## 工程与数据

- [ ] 六个 Maven 模块可编译，`mall-admin` / `mall-api` / `mall-job` 三进程可启动
- [ ] 统一返回体、错误码分段、全局异常生效
- [ ] 一期全部数据表按文档 DDL 建好，生成列唯一约束（`active_mark` / `success_mark` / `enabled_product` / `dedup_mark`）生效
- [ ] `store.level_paid_amount` 注释与计算口径均为「已付对价，等级变更置值不累加」
- [ ] `store_event` 含 `proof_images`；`payment` 含 `offline_method`；`store` 含持卡人特批字段
- [ ] `wallet_log.biz_type` 不含 `WITHDRAW_REJECT`；`performance_bonus.performance` 为不可编辑快照
- [ ] 初始化数据包含三档位、默认配置、默认业绩规则、默认协议

## 门店与档位

- [ ] 短信验证码 5 分钟有效、同号 60 秒限流
- [ ] 扫码注册自动绑定上级，`path` 以 `/` 结尾且层级正确
- [ ] 未实名不能加盟、不能下单；未加盟只能浏览；未加盟不能生成邀请二维码
- [ ] 统一购买路径判定与 3.3 判定表五条分支完全一致，档位高低按 `sort` 比较
- [x] 窗口期判定为 `now <= upgrade_deadline`，到期当天仍可补差、之后走预存
- [x] 窗口期内补差金额 = 目标档位费 − `level_paid_amount`，且 `level_paid_amount` 置值不累加
- [x] 5 万档选 3 万档按全额预存、等级与已缴对价不变
- [x] 超期升更高档按全额收款、旧对价不抵扣，后台建单页有提示
- [x] 预存不校验已缴金额；同档位可重复预存
- [x] 补差 ≤ 0 时拒绝并记录告警日志
- [x] 预存活动限次只统计已支付预存单；补差单不消耗活动次数
- [x] 活动下架后常驻入口仍可用
- [ ] 代客加盟强制上传证件与纸质协议，`auth_status=1`、`sign_type=2`，走 JOIN 提成规则
- [ ] 代客加盟/线下收款记录收款方式（现金/转账/刷卡）与实际收款时间
- [ ] 已加盟门店无法走代客加盟

## 协议与档位权益

- [ ] 协议建单时只校验勾选、不落库；支付成功事务内写 `store_agreement`
- [ ] 后台保存档位时，非最高档无法开启 `long_term` / `has_bonus` / `has_gift`

## 钱包与资金

- [ ] 所有余额变动均经 `WalletService` 且写 `wallet_log`，禁止直接 update
- [ ] 预存只能订货、佣金只能提现，佣金余额不可用于下单
- [ ] 下单扣预存与取消退回原子执行，取消后预存全额退回
- [ ] 并发扣减不超扣，多钱包加锁按 `store_id` 升序
- [ ] 佣金余额可为负，后续入账先抵扣，提现前校验可用余额
- [ ] 提现申请/驳回/打款失败均不写 `wallet_log`，仅打款成功写 `WITHDRAW, -1`

## 商品、订单与支付

- [ ] 三档价按等级自动取价，缺价档位置灰且后端拒绝下单
- [ ] 买赠按瓶折算倍数计算，赠品 0 元、不计金额/业绩/提成
- [ ] 同商品任一时刻仅一条 `enabled=1`，切换时先停用旧规则；不支持预排
- [ ] 订货订单状态只含 0/1/2/3/4，无异常/退款态；门店端不出现相关文案
- [ ] 未支付订单 10 分钟自动取消（订货/加盟/预存统一）
- [ ] 纯余额订单不创建支付单，直接进入待发货
- [ ] 取消订单两阶段：先关单查单，确认未支付后才退预存
- [ ] 扫呗 4.3 参数与返回值未被改写，`return_code` 与 `result_code` 均为 01 才调起
- [ ] 回调验签 + 金额比对 + 幂等，重复 10 次只入账 1 次
- [ ] 关单时 4.5 查单已支付 → 回滚取消并补记成功
- [ ] 已完成关单后收到成功回调 → 支付单置成功、业务单转异常并告警
- [ ] `closeBizOrder` 只在事务外或定时任务调用，禁止在支付成功事务内调用
- [ ] 发货支持物流与其他两种方式，门店确认收货后完成

## 提成与业绩

- [ ] 首次加盟任意档位上级可拿 10%/3%；其余场景仅 5 万档上级可拿
- [ ] 未加盟门店与厂家不参与提成；预存余额订货不产生提成
- [ ] 提成金额向下取整到分，`uk_biz_store` 保证不重复发放
- [ ] 冻结受益人提成照常入账
- [ ] 业绩按支付成功时间归属月份，余额订货不计业绩
- [ ] 月结取上月末档位，按结算时子树汇总，全额累进
- [ ] 附录 A 第 7 步业绩 110500、奖励 552.5 准确
- [ ] 结算月份内存在冻结区间不结算且不补发
- [ ] 未命中档位不写奖励记录；冲正为 0 仍写记录
- [ ] 结算前修正只新增 `ADJUST` 流水；结算后修正只走 `revision_of` 冲正链与差额流水
- [ ] 冲正记录 `bonus_amount` 为修正后应发，`wallet_log` 只记差额

## 提现

- [ ] 仅 15 日与月末可申请，最低额后台可配
- [ ] 申请冻结金额，可用余额校验正确
- [ ] 审核通过条件更新防重复打款；驳回解冻
- [ ] 批次生成、清单导出（门店名/手机号/户名/开户行/卡号/金额）与操作日志
- [ ] 标记已打款上传截图；标记打款失败填原因并解冻
- [ ] 打款失败后门店可见原因并可下个窗口重新申请
- [ ] 批次超 7 天未打款告警
